Evidence & Honesty

Separate published BDH concepts from our educational implementation.

🟢 Published BDH concept

Synaptic state is updated through activity-dependent, Hebbian-like mechanisms described in published BDH work.

🔵 Our implementation

Interactive toy model demonstrating temporary associative memory through transparent controls and visible state changes.

🟠 Not claimed

This is not an official BDH implementation, checkpoint, or biological simulation.

05 · From Toy Model to BDH

Conceptual bridge — not a claim of biological equivalence.

technical honesty
activity

Neuron firing

Repeated co-activation creates the opportunity for a synaptic update.

plasticity

Synapse changes

Our toy weight increases when a cue and target are active together.

memory

Temporary trace

Decay and interference make the trace less reliable over time.

BDH is a brain-inspired architecture. Its published paper describes inference-time working memory through synaptic plasticity with Hebbian learning in a spiking-neuron model. Synapse Lab simplifies that mechanism into an interpretable experiment.
